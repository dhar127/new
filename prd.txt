1. Document Overview
This Product Requirements Document (PRD) defines the functional requirements, expected system behavior, and feature
scope for KTern.AI's Agentic AI-driven License Optimization and Segregation of Duties (SoD) Analysis modules, as
contracted with Lotte Chemical.
The document is structured in two primary streams:
o Stream 1: License Optimization — AI-driven analysis of SAP user licenses, roles, transactions, and
authorization objects to identify optimization opportunities and reduce costs.
◦ The proposed pricing is applicable for 12 runs per year for a duration of 3 years.
o Stream 2: SoD (Segregation of Duties) Analysis — AI-powered detection of access conflicts, critical violations,
and compliance gaps across SAP authorization landscapes.
◦ The proposed pricing is applicable for 90 runs per year for a duration of 3 years.

2. Need Statement
Lotte Chemical manages a large-scale, multi-geography SAP landscape. Maintaining SAP license compliance, cost
efficiency, and access governance at this scale using manual methods is no longer sustainable. The key pain points
driving this initiative include:
o No single source of truth for SAP user license consumption across business units and geographies.
o Manual license classification requiring significant effort from SAP BASIS and Security teams.
o Lack of real-time visibility into role usage, authorization footprints, and SoD risk exposure.
o Inability to proactively detect compliance violations prior to audits.
o High cost of over-licensed users who do not consume the access they are assigned.
o No repeatable, scalable governance model for ongoing license and SoD management.
KTern.AI addresses these pain points through its Agentic AI-driven License Optimization and SoD Analysis agents,
delivering automated, continuous, and audit-ready intelligence across the SAP landscape.

3. Recommendations – Object Level Cleaning & Role Based Cleaning
Object-Level Cleaning (Focus: Professional License Objects)
1. Eg: Filter “Professional License” objects only
o Step 1: Object Traceability: Identify all roles containing the auth object (e.g., “ZX”) - (irrespective of
used/unused)
o Step 2: Role Assignment: For each role (e.g., F_LFA1) that contains the object:
▪ State the number of users assigned & List the user names
o Step 3: Usage & License Segregation: Based on trace:
▪ Identify users who actually use the object
▪ Classify users into:

▪ High privilege (Professional required)
▪ Lower privilege (Functional/Productive sufficient)
o Step 4: Role Optimization:
▪ Create a separate high-privilege role for the identified Professional users
▪ Remove high-privilege objects from the old role (F_LFA1)
▪ Retain only required objects for remaining users in the old role (F_LFA1)
2. Role-Based Cleaning (Focus: Usage Efficiency)
3. Step 1: Role Assignment Analysis: Identify all users assigned to the role
4. Step 2: Usage Validation: Identify users who:
o Did not use any objects in the role
o Or have very low usage (specify it clearly)
5. Step 3: Pattern Identification: Evaluate across users:
o If majority unused (give count) → role is a cleanup candidate
o If partially used (give count) → role requires optimization (object cleanup)
6. Step 4: User-Level Cleanup: For users not using the role:
o Identify other unused roles assigned
o Recommend removal of unused role assignments

11. Glossary

Authorization Object An SAP security element that controls access to business functions, fields, and activities within the system.
Enhancement Ticket A formal request for a feature or change that is outside the signed SoW, processed under the KTern.AI SLA.
Firefighter Access Emergency privileged access in SAP, typically managed via SAP GRC firefighter IDs for break-glass scenarios.
License
Classification
The categorization of an SAP user's license type (Professional / Functional / Productivity) based on their access and
usage patterns.
OTC Order-to-Cash — the end-to-end business process from customer order creation through billing and cash collection.
PRD Product Requirements Document — this document.
Role Utilization The degree to which authorization objects and transactions within an assigned role are actively used by the assigned
user.
SLA Service Level Agreement — the KTern.AI policy governing support response times and enhancement ticket delivery.
SoD Segregation of Duties — the principle of separating conflicting business process steps across different users to reduce
fraud and error risk.
SoW Statement of Work — the signed contractual document between KTern.AI and Lotte Chemical defining the scope of
delivery.
T-Code Transaction Code — an SAP shortcut that executes a specific SAP function or program.
USMM / LAW SAP License Administration Workbench and User System Measurement — SAP tools for license measurement
and compliance.
